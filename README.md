# Deutsch bewusst · Telegram-бот — Этап 1

Каркас, каталог продуктов, модуль оплаты, выдача минибука.

## Структура

```
netlify/functions/telegram.mjs   вебхук — точка входа
src/config.js                    имена таблиц и переменные окружения
src/db.js                        весь доступ к Supabase
src/ui.js                        тексты, клавиатуры, форматирование
src/menu.js                      /start, разделы, карточки, кабинет
src/payment.js                   оплата, приём квитанций, админ-подтверждение
src/bot.js                       сборка бота
scripts/set-webhook.mjs          установка вебхука
```

## Переменные окружения (Netlify → Site settings → Environment variables)

| Имя | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `SUPABASE_URL` | URL проекта Supabase |
| `SUPABASE_SERVICE_KEY` | **service_role** ключ, не anon |
| `ADMIN_CHAT_ID` | `-1004339011404` |
| `OWNER_TG_ID` | твой личный tg_id — узнать командой `/whoami` |
| `WEBHOOK_SECRET` | любая случайная строка, например `db_9f3k2xQ` |

## Запуск

1. Залить код в репозиторий, подключить его к Netlify.
2. Прописать переменные окружения, дождаться деплоя.
3. Установить вебхук с локальной машины:

```bash
BOT_TOKEN=... SITE_URL=https://твой-сайт.netlify.app WEBHOOK_SECRET=... node scripts/set-webhook.mjs
```

В ответе должно быть `"ok":true` и `"url"` с адресом сайта.

4. Написать боту `/whoami`, скопировать свой id в `OWNER_TG_ID`, передеплоить.

## Как включить минибук

1. Отправь PDF минибука **в админ-группу** — бот ответит его `file_id`.
2. В Supabase → SQL Editor:

```sql
update products
   set payload     = jsonb_build_object('file_id', 'ВСТАВИТЬ_FILE_ID'),
       price_eur   = 12.00,
       title       = '📘 Минибук с упражнениями',
       description = 'Текст карточки',
       is_active   = true
 where slug = 'minibook';
```

3. Написать боту `/start` и проверить весь путь до выдачи файла.

# Этап 2 — группы, лист ожидания, помесячная оплата


## Порядок обновления

1. Запустить миграцию `002_stage2_groups.sql` в Supabase → SQL Editor.
2. Залить обновлённые файлы в GitHub (файлы с теми же именами заменяются).
3. Netlify пересоберётся сам.

## Как это работает

**Запись без оплаты.** Человек бронирует место и выбирает удобное время.
Место занято, счётчик растёт, деньги пока не берутся.

**Счёт выставляешь ты.** Команда `/groups` в чате с ботом → выбрать группу →
видно список участников и кто какое время выбрал → кнопка
«Выставить счёт всем неоплатившим». Бот рассылает сумму и реквизиты.

**Оплата** идёт через тот же модуль, что и минибук: квитанция → имя
отправителя → твоё подтверждение. После подтверждения участник получает
статус `active`, поле `paid_until` = +1 месяц, и ссылку на чат группы.

**Продление.** Раз в сутки бот проверяет, у кого заканчивается оплата,
и присылает напоминание с кнопкой «Продлить». Через `grace_days` дней
после окончания участник возвращается в статус `reserved`, а тебе
приходит уведомление.

## Что заполнить руками

```sql
-- расписание, когда согласуешь с группой
update groups set schedule_text = 'вт/чт 18:00' where level = 'A0';

-- ссылка на закрытый чат группы (бот должен быть админом чата)
update groups set chat_invite_link = 'https://t.me/+xxxxx' where level = 'A0';

-- твой tg_id, чтобы приходили уведомления о записях
update teachers set tg_id = ВАШ_ID where role = 'owner';
```

## Настройки этапа 2 (таблица settings)

| Ключ | Значение по умолчанию | Что делает |
|---|---|---|
| `waitlist_levels` | `A2,B1` | уровни для листа ожидания |
| `renew_remind_days` | `3` | за сколько дней напоминать о продлении |
| `grace_days` | `3` | сколько дней терпим просрочку |
